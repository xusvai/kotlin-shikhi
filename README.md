## 📖 Kotlin শিখি কী?

**Kotlin শিখি** হলো বাংলা ভাষায় Kotlin শেখার একটি beginner-focused learning platform।

Kotlin-এর বিষয়গুলোকে ছোট ছোট lesson ও topic-এ ভাগ করে সাজানো হয়েছে, যাতে একজন নতুন learner একসাথে অনেক কিছু না শিখে **ধাপে ধাপে concept বুঝতে পারে**।

প্রতিটি lesson নির্দিষ্ট একটি concept-এর ওপর focused এবং প্রয়োজন অনুযায়ী Kotlin code example ব্যবহার করে বিষয়টি বোঝানো হয়েছে।
